# 产后抑郁的妈妈？

> 更新时间：2026-09-19 (UTC+8)

前不久COCO李玟因抑郁症离世，令人唏嘘之余也再次提升了大众对于抑郁症的关注度。

据估计，全世界每年有5%的成年人患有抑郁症。但大众通常对于抑郁症缺乏理解，让这种全球性的健康危机仍然被忽视，这其中也包括产后抑郁症。

世界卫生组织和多家专业机构的研究表明：

60% 到 80% 的围产期妇女在孕期和产后会有不同程度的抑郁情绪。其中大多数会在几周内好转，20% 会发展为临床抑郁症，极少数情况严重的，可能会酿成悲剧。

而《2022年国民抑郁症蓝皮书》数据显示，中国每5个产妇中就有1个患抑郁症，63%的女性曾患产后抑郁。产后抑郁，已经成为了每一位产妇都不容忽视的健康问题。

那什么是产后抑郁症，我们唯有先了解才能更好地去帮助。

01

大多数人产后都会经历心绪不良

新生儿出生后的第三四天左右，大约80%-85%的新妈妈会经历一个情绪容易波动的阶段。目前主要认为是由于孕期和产后激素的快速变化，内分泌失调引起的情绪变化。这种状况在英文中被称作「Baby Blues」（婴儿忧郁），这是普遍、正常的短暂性适应不良症，不会持续很长时间，大多数人会在两三周后恢复常态。

同时研究显示，「Baby Blues」或者早期的抑郁情绪与妈妈的社会、教育背景、家庭关系、是否有心理疾病史及分娩是否顺利没有关系。它可能发生在任何人身上，少数爸爸也会出现产后抑郁的表现。

02

产后抑郁需要专业确诊

抑郁情绪不一定是病症的临床抑郁症的前兆。但如果抑郁情绪持续存在，生活压力、身体疲劳、缺乏支持都会成为刺激源，增加发展成为抑郁症的风险。

一般抑郁症可能会有以下这些特点：

-持续低落的情绪-兴趣和乐趣丧失-疲倦、无力，休息后也难以恢复精力-入睡困难、早醒或过度睡眠-自我否定内疚感，觉得自己照顾不好宝宝-食欲改变，食欲减退或暴饮暴食-注意力和集中力下降，常常感到焦躁不安-消极思维和自杀倾向

临床的抑郁症需要专业的精神科医生来诊断，并进行抗抑郁治疗。如果怀疑自己有抑郁症应该前往医院来确诊。

03

什么会导致产后抑郁？

目前对于产后抑郁症产生的原因，国际上的相关各学界也还没有一个明确的定论。有些研究指出是产后激素水平极速变化导致的抑郁问题。

但也有研究发现，有些新生儿父亲和刚刚领养孩子的母亲也会出现产后抑郁症的症状，而他们并没有经历内分泌变化的生理过程。

所以说抑郁症的发病可能不是单一生物学原因引起的，它可能是个人特质、生活事件和环境相互作用的结果。

// 与产妇个人相关的风险因素

有抑郁症史和家族病史

曾遭受过暴力虐待

多思多虑、敏感多疑、易紧张会增加围产期抑郁的风险

多病、孕期出现严重的并发症者

对内分泌变化敏感，情绪波动较大且对日常生活影响严重的人

事无巨细的完美主义者

// 生活（压力）事件因素

怀孕过程不顺利

痛苦的分娩体验，产后出现严重并发症

孩子有健康问题，比如早产、先天性疾病等等

经常受到责备甚至虐待

夫妻关系紧张，家庭冲突不断

工作相关压力，无法按自己的心愿掌控自己和孩子的生活

// 家庭环境因素

缺乏家庭支持

照顾婴儿是一件24小时不间断的工作，但这个重担往往只压到了妈妈头上。爸爸的缺失没有帮助，妈妈就很容易陷入疲惫和焦虑中。即使有帮手，也会在情感和精神上感到无助。而且一旦宝宝出现意外，甚至只是哭闹，指责的矛头也会首先指向母亲。

中国“婆婆”因素

大部分的产妇平时与婆婆并不熟悉，互相缺乏了解和默契，而当产妇身心极为脆弱的时候，又需要婆婆的贴身照顾，就难免会一时难以适应。但我们也不能一味地将各种压力因素归咎于婆婆。

照顾产妇和婴儿本来就是一件强度很大的工作，除了体力精力付出还需要专业知识、团队合作及学习能力。

为母则刚，不鼓励情绪表达

在传统文化环境中，母亲大多是任劳任怨、无怨无悔的坚毅形象。如果偏离这样的形象，就有可能被认为不合格的母亲。而且作为成年人我们也通常被要求“情绪稳定”，“不把想法摆在脸上”。在这种价值观念的裹挟下，我们开始害怕、排斥一些负面的情绪。

妈妈会习惯于隐藏情绪，选择自我消化。而如果开始表达负面、低落甚至是激烈的情绪，就可能会被说“矫情”。

04

母乳喂养降低or提升抑郁风险?

2021年底，Breastfeed Med杂志发表了一篇综述，提示了母乳喂养与产后抑郁的关系。研究结果显示，不进行纯母乳喂养的女性，患产后抑郁症的几率升高89%。

但这不能简单说母乳喂养会降低抑郁症风险。另一个发表于Matern Child Health J的一篇文章 [1]基于Avon亲子纵向研究（ALSPAC）的数据，探讨了母乳喂养与产后抑郁的相关性。研究将母乳喂养意愿和结果进行了分组，显示愿意并实现母乳喂养的母亲，产后抑郁的风险降低；计划母乳喂养却因为各种原因没能实现的，产后抑郁风险增加。另外值得注意的是，产前没有母乳喂养意愿却实施了母乳喂养的母亲，产后抑郁的风险也会增加。

05

如何应对产后抑郁？

产后抑郁症的治疗主要通过心理治疗、抗忧郁药物治疗、物理康复治疗等方法进行治疗。轻度产后忧郁可能仅需要心理治疗就可以改善，严重的需要配合药物治疗。

产妇可以找到爱你，并且信任的人，有可能是家人、朋友或者医生去倾诉，让他们了解。为自己找到“小确幸”，坚持每天走走或做些什么来增加：多巴胺、内啡肽、血清素、催产素的分泌。这些是能让人快乐的激素。

而家人也不要把注意力全都集中在孩子身上，忽略了产妇，要注意她的日常表现、心理状态，发现产妇心情不好要表示理解、关心，而不要责怪。
